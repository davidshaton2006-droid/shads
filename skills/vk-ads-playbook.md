# Плейбук: настройка и ведение кампаний в VK Ads (VK Реклама)

Справочник для ИИ-агента и человека перед созданием/правкой рекламной кампании. Каждое нетривиальное утверждение — с источником. Актуально на сентябрь 2026 для нового кабинета VK Реклама (ads.vk.ru).

---

## 1. Порядок настройки с нуля

1. **Установить пиксель VK Рекламы на сайт заранее, до запуска кампании.** Без него оптимизация под целевые действия и сбор аудиторий для ретаргетинга невозможны.
2. Создать кампанию → выбрать тип (конверсии: сайт / каталог / приложение / лид-форма, либо медийный охватный формат) → указать объект рекламирования (адрес сайта) и целевое действие (показы / клики / конверсии).
3. Настроить бюджет и стратегию ставок.
4. Настроить группу объявлений: гео, время, демография, интересы, контекстный таргетинг (ключевые фразы + минус-фразы), аудитории (ретаргетинг/look-alike), устройства, места показа.
5. Создать объявления — формат и креативы.
6. Отправить на модерацию (обычно от нескольких минут до 24 часов).

## 2. Пиксель и события — обязательный первый шаг

- Регистрация на ads.vk.ru → подтверждение email → раздел «Сайты» → «Добавить пиксель» → указать домен.
- Установка кода: прямая вставка в `<head>`/`<body>` как можно ближе к началу страницы, либо через плагины CMS (WordPress, 1С-Битрикс, Tilda), либо через Google Tag Manager (кастомный HTML-тег на все страницы).
- **Включить автоматический поиск событий** — пиксель сам начнёт отслеживать клики по кнопкам, отправку форм, покупки и другие базовые действия без ручной разметки каждого события.
- Для связи онлайн/офлайн данных и загрузки конверсий из CRM — использовать параметр USER_ID для синхронизации пользователей.
- Проверка работы: статус меняется с «Данные не поступают» на «Данные поступают» после первых событий; дополнительно проверяется через консоль разработчика (F12 → Network, поиск по идентификатору пикселя).

Источник: [Установка пикселя VK Рекламы — пошаговый гайд](https://osipenkov.ru/vk-ads-pixel/)

**Правило для агента:** не запускать кампанию с целью «конверсии», если пиксель не показывает статус «Данные поступают» и нужное событие не настроено — оптимизация в этом случае будет работать вслепую, без реального сигнала.

---

## 3. Выбор цели кампании — под задачу, не по умолчанию

- Не выбирать «трафик», если реальная задача — заявки/продажи: цель определяет, под что алгоритм VK оптимизирует показы, и «трафик» оптимизируется под клики, а не под конверсии.
- Для сбора контактов внутри платформы (без перехода на сайт) — формат «Лид-форма».
- Для интернет-магазинов — товарные баннеры.
- Для охватных задач без цели «действие» — медийные форматы отдельно от кампаний на конверсии, не смешивать логику оптимизации.

## 4. Бюджет и стратегия ставок

- Стратегия **«Минимальная цена»** — рекомендуемая по умолчанию площадкой для большинства задач (алгоритм сам ищет наиболее дешёвые релевантные показы/клики/конверсии в рамках заданного бюджета).
- Стратегия **«Предельная цена»** — используется, когда важно жёстко ограничить цену за конверсию/клик, даже ценой объёма показов.
- Для теста новой связки (оффер + аудитория + креатив) — стартовый дневной бюджет порядка **500–1000 ₽/день**, чтобы оценить жизнеспособность гипотезы до масштабирования.

## 5. Таргетинг и аудитории

Настраиваются на уровне группы объявлений:
- География и время показа (включая гео-метку для локального бизнеса).
- Демография (пол, возраст).
- Интересы — из предложенных VK категорий.
- Контекстный таргетинг — ключевые фразы и минус-фразы (аналог семантики в поисковых системах, но здесь про интерес/контекст, не буквальный поиск).
- Аудитории: ретаргетинг посетителей сайта (через пиксель) и look-alike сегменты на основе текущих клиентов/конверсий.
- Устройства: мобильные / десктоп / оба.
- Места показа: автоматически, либо вручную — ВКонтакте, Одноклассники, проекты VK, рекламная сеть.

**Правило: не одна широкая аудитория, а минимум 2–3 параллельных сегмента** (например: холодная по интересам, look-alike, ретаргетинг) — для сравнения эффективности и последующего перераспределения бюджета в пользу лучшего сегмента.

## 6. Форматы и креативы

Доступные форматы: универсальное объявление (адаптивный базовый формат), карусель (3–6 слайдов с разными ссылками), коллаж (2–10 изображений/видео в сетке), товарные баннеры, лид-форма, видеореклама.

- Готовить **2–3 варианта креатива на группу** с разными офферами/форматами — алгоритм VK сам перераспределит показы в пользу лучше работающего варианта, но только если есть из чего выбирать.
- Ограничивать частоту показов одного креатива одной аудитории, чтобы не выжигать её за несколько дней — признак выгорания: падение CTR при неизменном охвате.
- Отдельный, не смешанный с холодным трафиком, бюджет на ретаргетинг — обычно самый дешёвый и конверсионный сегмент, который не должен «теряться» в общем бюджете на холодную аудиторию.

## 7. Модерация и запуск

- После настройки кампания уходит на модерацию — от нескольких минут до 24 часов.
- До прохождения модерации показов не будет — закладывать этот срок при планировании даты старта рекламы (например, для акций с ограниченным сроком).

Источник: [Elama — Как запустить кампанию в новом кабинете VK Реклама, 2026](https://elama.ru/blog/kak-zapustit-reklamnuyu-kampaniyu-v-novom-kabinete-vk-reklama-poshagovaya-instrukciya/)

## 8. Чек-лист перед запуском кампании

- [ ] Пиксель установлен, статус «Данные поступают» подтверждён
- [ ] Нужное событие конверсии настроено и проверено (не только «автопоиск событий» по умолчанию, если задача специфична)
- [ ] Цель кампании соответствует реальной задаче (не «трафик» при задаче «заявки»)
- [ ] Минимум 2–3 сегмента аудитории заведены отдельно для сравнения
- [ ] 2–3 варианта креатива подготовлены на группу
- [ ] Стартовый бюджет — тестовый (500–1000 ₽/день), не полный бюджет сразу
- [ ] Ретаргетинг вынесен в отдельную группу с отдельным бюджетом
- [ ] Заложено время на модерацию при планировании даты старта

## 9. Правила для ИИ-агента, ведущего кампанию автономно

- Не запускать кампанию с целью «конверсии» без подтверждённого статуса пикселя и настроенного события.
- Не расширять бюджет тестовой кампании сверх стартового лимита без явного подтверждения человека — расширение бюджета относится к high-risk действиям (см. guardrails архитектуры системы).
- При признаках выгорания креатива (падение CTR при стабильном охвате на одну и ту же аудиторию) — предлагать замену креатива, не увеличение ставки на том же креативе.
- Ретаргетинг и холодный трафик — не объединять в одну группу/бюджет ни при каких оптимизациях.
