# Плейбук: настройка и ведение кампаний в Яндекс.Директе

Справочник для ИИ-агента и человека перед созданием/правкой рекламной кампании. Каждое нетривиальное утверждение — с источником. Актуально на сентябрь 2026, правила площадки стоит сверять перед стартом.

---

## 1. Структура аккаунта — с чего начинать

**Правило: Поиск и РСЯ — всегда разные кампании, никогда не смешивать.**

Причина не организационная, а в поведении аудитории и оптимизации:
- На поиске пользователь ищет решение здесь и сейчас, с явным намерением.
- В РСЯ показ идёт по интересам/поведению — человек мог интересоваться темой раньше, сейчас интерес не гарантирован.
- Смешение бьёт по оптимизации: повышение ставок ради сегмента, эффективного в РСЯ (например, определённый пол/устройство), может задирать цену кликов на поиске для нерелевантной там аудитории — и наоборот.
- Раздельные кампании дают: отдельную стратегию оптимизации на каждый канал, разные креативы (текст vs баннеры/медиа), раздельный контроль бюджета.

Источник: [РСЯ или поиск в Яндекс Директ — в чём разница](https://andata.ru/blog/kontekstnaya-reklama/v-chem-razniza-rsya-i-poisk-yandex-direct)

**Группы объявлений — по смыслу запроса, не по 1 фразе и не по 50.**
Коммерческие и информационные запросы («заказать услугу» vs «как сделать самому») — в разные группы: у них разное поведение, разная конверсия, разная нужная ставка. Смешение в одной группе — частая причина завышенной цены клика.

## 2. Семантика и минус-слова

- Сбор ключевых фраз — через Wordstat, с разбивкой по коммерческим/информационным запросам.
- **Избегайте максимально широких фраз** («ремонт квартиры») — они привлекают любопытствующих, студентов, конкурентов вместо целевых клиентов. Собирайте фразы конкретнее, с указанием намерения (купить/заказать/цена/для конкретного города).
- **Список минус-слов формируется до запуска, не после.** Пустой список — прямой путь к показам по мусорным запросам.
- **Регулярный (минимум еженедельный) разбор отчёта по поисковым запросам** и пополнение минус-слов — без этого шага, по расчётам практиков, неделя простоя может стоить 50 000–100 000 ₽ на средних бюджетах.
- **Автотаргетинг — не «включить на максимум».** Без явных ограничений алгоритм начинает показываться по нерелевантным запросам, обучаясь за счёт бюджета рекламодателя.

## 3. Стратегии ставок — когда автостратегия работает, а когда нет

**Правило запуска нового аккаунта/кампании без истории: НЕ начинать сразу с оплаты за конверсии.**

Причины:
- Алгоритму нужно минимум **~10 конверсий в неделю на кампанию** для стабильного обучения; оптимальнее — от 50 конверсий в месяц.
- Период обучения занимает 1–2 недели, и в это время результаты нестабильны, а цена конверсии — выше целевой.
- При паузе кампании дольше 7 дней обучение может перезапуститься с нуля.
- Частые изменения настроек в период обучения сбивают алгоритм.

**Практическая последовательность для нового проекта:**
1. Первые 1–2 недели — стратегия «Максимум конверсий» **без** включённой оплаты именно за конверсии (то есть оптимизация идёт по целям, но платите вы всё ещё за клики) — это позволяет накопить статистику без риска дорогих случайных конверсий на старте.
2. Если трафика/конверсий мало для накопления статистики быстро — используйте микроконверсии (добавление в корзину, просмотр контактов, клик по телефону) как промежуточные сигналы для обучения, пока не наберётся достаточно макроконверсий (покупка/заявка).
3. Оффлайн-конверсии (звонки, покупки в точках) — загружать в Центр конверсий не реже двух раз в неделю, если они есть в бизнесе.
4. Переход на оплату за конверсии — только после накопления достаточной статистики по целевой цели.

## 4. Метрика и цели — обязательное условие

- Цели в Метрике настраиваются **до** запуска кампании — минимум на отправку формы и на звонок (если есть коллтрекинг).
- Без корректно настроенной и привязанной цели система будет оптимизироваться по неверным сигналам, что напрямую ведёт к сливу бюджета — это одна из самых частых ловушек по наблюдениям практиков.
- Автостратегии без привязки к Метрике не работают в принципе — им нечем измерять успех.

## 5. Объявления

- **Не использовать шаблонные формулировки** («Качественно. Недорого») — они не выделяют объявление среди конкурентов и снижают CTR, что напрямую повышает цену клика через аукцион.
- Заполнять все доступные расширения: быстрые ссылки, уточнения, отображаемая ссылка — повышают CTR практически без дополнительных затрат.
- Готовить минимум 2–3 варианта текста на группу для последующего A/B — не полагаться на один вариант с самого начала.

## 6. РСЯ отдельно — чистка площадок

- РСЯ без регулярной чистки площадок — трафик со скликивающих сайтов и мобильных игр съедает бюджет впустую. Список исключаемых площадок нужно вести и пополнять так же, как минус-слова для поиска.
- Отслеживание аномального трафика (подозрение на скликивание конкурентами) — отдельная задача; по оценке практиков, необнаруженное скликивание может съедать 25–35% бюджета кампании.

## 7. Посадочная страница — не часть Директа, но часть результата

- Первый экран должен грузиться быстрее 3 секунд — иначе оплаченный клик теряется до того, как посетитель увидит оффер.
- Контактные данные и форма заявки — на виду, не спрятаны.
- Форма из 8+ полей отталкивает до 70% посетителей по наблюдениям практиков — чем короче форма, тем выше конверсия оплаченного трафика.

## 8. Чек-лист перед запуском кампании

- [ ] Поиск и РСЯ разнесены по разным кампаниям
- [ ] Семантика разбита по группам: коммерческие / информационные запросы — раздельно
- [ ] Стартовый список минус-слов собран до запуска
- [ ] Цели в Метрике настроены и привязаны (форма, звонок, при наличии — микроконверсии)
- [ ] Стратегия на старте — без оплаты за конверсии, пока не набрана статистика (см. раздел 3)
- [ ] У каждой группы — 2–3 варианта объявлений с расширениями (быстрые ссылки, уточнения)
- [ ] Посадочная страница проверена на скорость загрузки и заметность формы/контактов
- [ ] Запланирован регулярный (не реже раза в неделю) разбор поисковых запросов и площадок РСЯ

## 9. Правила для ИИ-агента, ведущего кампанию автономно

- Не переключать кампанию на оплату за конверсии, пока не накоплено ~10 конверсий/неделю по кампании.
- Не приостанавливать и не перезапускать кампанию, находящуюся в фазе обучения автостратегии (первые 1–2 недели), без крайней необходимости — это сбрасывает прогресс обучения.
- Разбор поисковых запросов и обновление минус-слов — выполнять не реже раза в неделю в автоматическом режиме, с логированием добавленных минус-слов.
- Любое изменение стратегии ставок или недельного/дневного бюджета — относить к действиям, требующим подтверждения человека, а не выполнять автономно (см. guardrails архитектуры системы).
